How the RAG Agent answers ANY question

Because Qdrant has all the meaning, and Neo4j has all the connections, the Agent orchestrates them.

User Question: "Find all users who interact with sammer727 AND have posted hate speech about protests, and check if a ticket is raised in Lucknow."
1
Qdrant Semantic Search
The Agent embeds "protests" and searches Qdrant for CONTENT and INCIDENT entities, applying the "Hate Speech" category filter.
qdrant.search(
  vector=embed("protests"),
  filter={
    "entity_type": "CONTENT",
    "broad_category": "HATE SPEECH"
  }
)
// Returns List of neo4j_ids:
["ad_111", "ad_222", "ad_333"]
2
Bridge (Pass IDs to Graph)
The LLM takes the exact IDs returned by Qdrant (representing the semantic match) and passes them into a Neo4j Cypher query as a variable list.
// The LLM generates this array
$qdrant_ids = ["ad_111", "ad_222", "ad_333"]

// The LLM constructs the Cypher query
// based on the user's complex conditions.
3
Neo4j Graph Traversal
Neo4j filters the Qdrant results through the social network AND checks the ticketing/location network simultaneously.
MATCH (c:Content) WHERE c.post_id IN $qdrant_ids
MATCH (u:Account)-[:POSTED]->(c)
MATCH (u)-[:CONNECTED_TO|INTERACTED_WITH]-(:Account {username: 'sammer727'})
MATCH (c)-[:BELONGS_TO]->(i:Incident)
MATCH (t:Ticket)-[:RAISED_FOR]->(i)
MATCH (t)-[:ASSIGNED_TO]->(:Location {name: 'Lucknow'})
RETURN u.username, t.status
