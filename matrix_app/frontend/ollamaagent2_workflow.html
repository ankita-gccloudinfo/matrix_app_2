The LangGraph State Dictionary

In LangGraph, all data is passed between nodes via a shared State dict. In ollamaagent2.py, this state is a plain TypedDict (28 keys, class State at line 601) — every node reads what it needs via state.get(...) and returns only the partial dict of keys it updates; LangGraph merges that into the shared state before the next node runs.
