ElevenLabs API Keys

Paste your free ElevenLabs API keys (up to 7), one per line. Every spoken reply uses the first key that still has credits; once a key comes back quota-exceeded it's automatically skipped and the next one is used — your browser's built-in voice is only used as a last resort if all keys run out. Each key auto-picks a voice it's actually allowed to use on its plan (free-plan keys 402 on most shared "voice library" voices) — leave Voice ID blank unless you specifically want to force one voice for every key.
